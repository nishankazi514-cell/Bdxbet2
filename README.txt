BDXbet Live Server Demo
========================

Files:
- app.py
- requirements.txt
- templates/index.html

Run:
1. Install Python 3.
2. Open terminal in this folder.
3. pip install -r requirements.txt
4. python app.py
5. Open http://127.0.0.1:5000

The server creates users.db automatically.

This package is a demo/test backend. Deposit and withdrawal requests are stored as pending records; no real payment transfer is performed.
